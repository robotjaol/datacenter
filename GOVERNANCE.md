# Governance

Jonathan Oktaviano is the initial project author and maintainer. Contributions are reviewed for evidence, licensing, reproducibility and engineering boundaries. Major architecture changes need a written decision record containing options, tradeoffs, assumptions and migration impact.

Releases use semantic versions for the toolkit. A changed physical equation or scenario that materially changes results is highlighted in release notes even when APIs remain stable. Keep prior evidence identifiable by configuration and artifact hashes.

Review status is explicit: proposed, reviewed, accepted or superseded. An accepted repository contribution is not a professional engineering sign-off or approval for construction. Governance roles may expand through documented maintainer agreement.
