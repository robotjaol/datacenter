# MOP-001 — Planned change record template

Fields: change ID; objective; asset/path boundary; approved drawings; configuration backup; prerequisite state; affected load; remaining capacity; dependent systems; author/reviewer/approver; communication plan; work window; permit references.

Before approval, attach the engineered procedure with verified equipment identification, isolation and restoration requirements, expected observations, hold points, stop criteria, rollback path and independent checks. Assess concurrent work, emergency response and recovery timing. This generic record does not authorize or describe a switching sequence.

During execution, record actual timestamps, observations, deviations, approvals at hold points and configuration changes. Stop if prerequisites no longer hold. Afterward, reconcile final topology, alarms, metering, capacities, configuration backups and asset status. Capture lessons and close only with operations acceptance.
