# Security and sensitive information

This repository is an offline concept toolkit. It contains no PLC endpoints, cloud credentials or live operational integrations. Do not commit secrets, real access procedures, confidential floor plans, badge details, customer records or unapproved operational data.

For ordinary software defects, use a minimal synthetic reproducer in an issue. For a vulnerability that would expose sensitive information in a future connector, use GitHub private vulnerability reporting if enabled; otherwise contact the maintainer through a verified private channel rather than posting exploitable confidential detail publicly. No unverified email address is prescribed.
