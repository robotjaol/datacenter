# Procurement, construction and handover

Develop packages for site/civil, building shell, electrical, mechanical, controls, fire/security and commissioning. Each package needs a scope boundary, interface matrix, performance requirement, submittal register, inspection/test plan, lead-time risk and acceptance evidence.

Procurement compares compliance exceptions, lifecycle cost, maintainability, support, spares, efficiency curves and integration requirements. Concept nameplates and financial allowances must be reconciled to quotations before award. Maintain approved alternatives and vendor-change control.

Construction gates: site readiness; foundations/underground coordination; weather-tight shell; equipment access/lifting plan; installation inspections; system completion; readiness for energization; functional testing; integrated testing; turnover. Durations in `milestones.csv` are planning allowances, not a promised project schedule.

Every change updates requirement impacts, drawings, settings, quantities, cost, risk, test procedures and as-built records. Handover includes open-issue severity, deferred seasonal tests, warranty, spares, training, O&M procedures and asset data. No project is complete solely because equipment is energized.
