# Reliability and maintainability

The executable example treats A and B as aggregate paths with identical synthetic unavailability, plus an independent common event. Analytical availability is compared with a seeded Monte Carlo sample. The Wilson interval quantifies sampling uncertainty only; it does not quantify uncertainty in the invented input rates.

The FMEA records component/function failure, consequence, detection, controls, owner and verification. It includes shared CHW, stale telemetry, battery aging and common upstream supply. The maintenance matrix distinguishes capacity arithmetic from unresolved isolation/routing questions.

Before quantitative reliability claims, develop a topology-specific fault tree, common-cause model, real failure/repair distributions, service dependencies and operating procedures. Treat planned maintenance overlap, human error, utility/fuel supply and environmental events explicitly. Do not translate this educational availability number into a Tier, SLA or predicted outage duration.
